## 우리 앱 호출량 (추정, 설계 기준)
| 동작 | 호출 | 비고 |
|---|---|---|
| 항공편 조회 | 도착 1 + 출발 1, 이후 **2분마다 재조회**(온보딩 후) | 사용자 1명이 1시간 앱을 열어두면 약 60회 |
| 출국장 대기 | 연결편 1회 + 2분마다 | 위와 같음 |
| 코스: 숙소 선택 | 주변 장소: 카테고리 7회(각 최대 3페이지) + 뷰티 키워드 7회 | 숙소 바꿀 때마다 |
| 코스: 구간 | 구간마다 1회(캐시) — 자동차는 카카오모빌리티, 6km 이상은 ODsay | 장소 3곳이면 5구간 |
| 코스: 후보 목록 | 보이는 후보 6개 × 1회(캐시) | 더보기 누르면 증가 |

→ **ODsay(30~1,000/일)가 가장 먼저 막힌다.** 실패하면 자동차로 대체되어 앱은 멈추지 않지만 대중교통 시간이 사라진다. 운영 전 유료 등급 또는 대중교통 구간 축소 결정 필요.
