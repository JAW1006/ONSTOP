## 이동시간·거리 출처 (코스 지도, A6 순차 경로)
| 구간 | 출처 | 실제/근사 | 화면 표기 |
|---|---|---|---|
| 자동차(직선 1.2~6km, 택시로 표시) | 카카오모빌리티 길찾기 `/api/route` | **실제 경로** — 시간·거리·경로 좌표 | "N분 · N.Nkm" |
| 대중교통(직선 ≥ 6km) | ODsay `/api/transit` | **실제 경로** — 시간·총거리(`totalDistance`, 도보 포함)·요금·탄 횟수 | "N분 · N.Nkm" |
| 대중교통 실패 | 카카오모빌리티로 대체 | 실제 경로(자동차) | 택시로 표시 |
| 도보(직선 ≤ 1.2km) | 앱 추정(직선 ÷ 4.5km/h) | **근사** | "약 N분", 거리 없음 |
| 조회 중·실패 | 앱 추정(직선 × 2분/km, 도보 거리면 도보 추정) | **근사** | "약 N분", 거리 없음 |
| 정적 장소의 `move` 필드 | 레거시 더미값 | 순차 경로 계산에 **쓰지 않음** | — |

구간 결과는 좌표 쌍 단위로 앱 실행 중 캐시한다(재조회 안 함). 근사 계수(2분/km)는 실제 대중교통보다 짧다 — [STATUS](../STATUS.md) "개선 후보".

## 알려진 사항
- 올리브영 운서점·테르엔 힐링센터는 쇼핑/휴식과 브랜드에 **같은 실제 지점이 다른 id로 중복** 등록(레거시 의도).
- 휴식(Rest) 장소는 데이터는 있지만 코스 빌더 카테고리(`ACT_KEYS`)에서 제외(레거시 의도).
- 데이유즈 시간 범위: 10곳 중 9곳이 3–6h, 호텔 오라만 3–9h(A9, [STATUS](../STATUS.md)).
