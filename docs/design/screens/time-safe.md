# Time-Safe — 온보딩 3단계

> 상태: 초안 · 최종 수정 2026-10-16 · 레거시: `Onboarding`(688–820줄), `App`의 lookup·폴링(533–615줄)
> 코드: [`src/features/time-safe/`](../../../src/features/time-safe/) · 공식: [time-safe](../../formulas/time-safe.md)

## 목적

언어·관심사를 고르고, 도착편과 연결편을 실시간 조회해 **외출 가능 시간**을 보여준 뒤 홈으로 보낸다.

## 진입/이탈

| 항목   | 내용                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 라우트 | `/onboarding?step=0                                                                    | 1   | 2` (기본 0) |
| 진입   | 앱 첫 진입(온보딩 미완료면 탭 화면 접근 시 여기로), 홈의 "다른 항공편 입력" → `step=2` |
| 이탈   | 두 항공편 조회 성공 후 CTA → 온보딩 완료 표시 → `/`                                    |
| 탭바   | 숨김                                                                                   |

## 구성 (위→아래)

| 블록   | 내용                                                                                                       | 문구 키                                          |
| ------ | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 헤더   | 그라디언트, 로고(40), 태그라인 2줄, 영문 슬로건 "Transit · Drop · Fly Light"(브랜드 고정 문구, 번역 안 함) | `brand.tagline.*`                                |
| 패널   | 위쪽 둥근 배경 패널, 단계 점 3개(현재 단계는 길게)                                                         | —                                                |
| step 0 | 언어 5개 행(국기·이름·체크), 다음                                                                          | `onboarding.language.title`, `common.next`       |
| step 1 | 관심 활동 7개 3열 그리드(아이콘·이름, 복수 선택), 다음                                                     | `onboarding.interests.*`, `category.*`           |
| step 2 | 도착편 입력 + 조회, 연결편 입력 + 조회, 오류 문구, **Time-Safe 결과 카드**, CTA, 안내                      | `onboarding.flights.*`, `flight.*`, `timeSafe.*` |

### Time-Safe 결과 카드

| 상태                                  | 표시                                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 아무것도 조회 안 됨                   | `timeSafe.needArrival`                                                                                       |
| 도착편만                              | 도착편 줄 + `timeSafe.needConnection`                                                                        |
| 둘 다 + 외출 가능                     | 도착편 줄, 연결편 줄, 총 환승 시간, **외출 가능 시간(큰 숫자)**, 도착·복귀 추천 시각, **버퍼 구성 줄(신규)** |
| 둘 다 + 외출 불가                     | 위 정보 + `timeSafe.cannotGoOut.*` 경고 박스                                                                 |
| 경고 OVER_24H / DEPART_BEFORE_ARRIVAL | 카드 안 경고 줄(신규 키)                                                                                     |

## 상태·데이터

| 항목                                             | 위치                                                                            |
| ------------------------------------------------ | ------------------------------------------------------------------------------- |
| 언어                                             | i18next (`i18n.changeLanguage`)                                                 |
| 관심사, 편명 입력값, 조회 요청 편명, 온보딩 완료 | `TripProvider`(`src/app/trip-state.tsx`)                                        |
| 항공편 조회                                      | TanStack Query `['flight', 'arrival'                                            | 'departure', 편명, apiLang]`, 재시도 없음 |
| 출국장 대기                                      | 연결편 터미널이 `P01`일 때만 `['securityWait']` 조회                            |
| 계산                                             | `resolveConnection` → `computeTimeSafe` (domain) — `useTimeSafe()`              |
| 재조회                                           | 온보딩 완료 후 2분(`FLIGHT_POLL_INTERVAL_MS`) 간격. 변경 알림 배너는 홈 이식 때 |

## 빈/오류/로딩

| 상황                                       | 표시                                                     |
| ------------------------------------------ | -------------------------------------------------------- |
| 조회 중                                    | 버튼 `onboarding.flights.lookingUp`, 비활성              |
| 편명 없음                                  | 조회 버튼 비활성                                         |
| 일치하는 편 없음(200 빈 목록 또는 **404**) | `flight.error.notFound` + `onboarding.flights.retryHint` |
| 시각 파싱 실패                             | `flight.error.noArrivalTime` / `noDepartureTime`         |
| 그 밖의 서버 오류                          | 서버 메시지 원문(레거시와 같음) + 재시도 안내            |
| 두 편 중 하나라도 없음                     | CTA 비활성 + `onboarding.flights.needBothHint`           |
| 외출 불가                                  | CTA 비활성 + `onboarding.flights.cannotGoOutHint`(신규)  |

## 레거시와 다르게 하는 점

| 항목                 | 레거시                           | 새 화면                                                                                                                             | 근거                                                                                                                                   |
| -------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 외출 가능 시간       | 도착~복귀(버퍼 0/50/30)          | 공항 밖~복귀(버퍼 50/50/30)                                                                                                         | A1·A5 결정                                                                                                                             |
| 버퍼 구성 줄         | 없음                             | "예상 소요 반영: 입국심사 **약** 50분 · 보안검색·출국심사 **약** 50분 · 게이트 여유 **약** 30분" (`timeSafe.bufferBreakdown`, 신규) | 도착→복귀 시각 차이와 외출 가능 시간이 50분 다르게 보이는 혼동 방지. 값이 미검증이라 확정값처럼 보이지 않게 "예상/약" 표기(2026-10-16) |
| **외출 불가 시 CTA** | 활성(눌러서 홈·코스로 진행 가능) | **비활성** + 이유 문구 "외출 가능 시간이 없어 코스를 추천할 수 없어요…"(`onboarding.flights.cannotGoOutHint`, 신규)                 | 2026-10-16 사용자 결정. 외출할 수 없는데 코스 추천으로 보내지 않는다                                                                   |
| 자정 넘김            | 외출 불가로 잘못 표시            | 출발을 "익일 HH:MM"으로, 정상 계산                                                                                                  | A2                                                                                                                                     |
| 24h 초과·출발 선행   | 없음                             | 경고 줄(`timeSafe.warning.*`, 신규)                                                                                                 | A2                                                                                                                                     |
| 404 응답             | 서버 영문 메시지 원문            | `flight.error.notFound`                                                                                                             | 다국어 사용자                                                                                                                          |
| 기본 편명            | `OZ117` / `OZ511` 하드코딩(TODO) | 빈 칸 + 예시 placeholder                                                                                                            | A12, 개발 편의값 제거                                                                                                                  |
| 단계                 | 컴포넌트 상태                    | URL `?step=`                                                                                                                        | 홈에서 바로 step 2로 진입                                                                                                              |
| 언어 변경 후         | 다음 수동 조회 때 반영           | 쿼리 키에 언어 포함 → 자동 재조회                                                                                                   | 항공사·공항명 번역 즉시 반영                                                                                                           |
