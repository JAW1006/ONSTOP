# 앱 골격 — 레이아웃·탭바·라우트

> 상태: 초안 · 최종 수정 2026-10-16 · 레거시: `App`, `Nav`, `NavItem`
> 코드: [`src/app/`](../../../src/app/)

## 목적
모든 화면이 공유하는 폰 프레임, 스크롤 영역, 하단 탭바, 라우트 구조.

## 라우트
| 경로 | 화면 | 탭바 | 레거시 `screen` | 상태 |
|---|---|---|---|---|
| `/onboarding` | 온보딩(언어 → 관심사 → 항공편) | 숨김 | `onboarding` | **완료** |
| `/` | 홈 | 홈 활성 | `home` | **완료** |
| `/luggage` | 짐 케어 | 짐 케어 활성 | `luggage` | 4단계 |
| `/course` | 코스 빌더 | 코스(FAB) | `course` | 4단계 |
| `/course/saved` | 저장된 코스 | 코스(FAB) | `savedCourse` | 4단계 |
| `/booking/:roomId` | 데이유즈 예약 | 예약 활성 | `booking` | 4단계 |
| `/bookings` | 예약 확인·내역 | 예약 활성 | `confirm` | 4단계 |
| `/my` | 마이 | 마이 활성 | `mypage` | 4단계 |

3단계에서는 각 경로에 제목만 있는 자리 화면을 둔다. 온보딩을 마치기 전에는 탭 화면에 들어가면 `/onboarding`으로 보낸다(`TabLayout`, 4단계 적용).

## 구성
| 블록 | 내용 | 토큰 |
|---|---|---|
| 프레임 | 데스크톱: 390×800, 둥근 모서리 34, 6px 테두리, 가운데. 모바일: 전체 폭·높이 | `--ts-app-width`, `bg-backdrop` |
| 스크롤 영역 | 프레임 안쪽, 탭바 높이만큼 아래 여백 | `--ts-nav-height` |
| 탭바 | 홈 / 짐 케어 / **코스(가운데 원형 FAB, 22px 돌출)** / 예약 / 마이 | `--ts-fab-size`, `shadow-fab`, 활성 `text-blue` / 비활성 `text-faint` |
| 바텀시트 | 프레임 안에서만 열린다(바깥 화면을 덮지 않음) | `--ts-overlay`, `rounded-2xl` |
| 항공편 변경 배너 | 탭 화면 공통, 프레임 상단(`FlightNotice`, `TabLayout`에서 렌더) | `bg-ink`, `--ts-shadow-toast` |

## 레거시와 다르게 하는 점
| 항목 | 레거시 | 새 앱 | 근거 |
|---|---|---|---|
| 화면 전환 | `screen` 문자열 상태 | URL 라우트 | 뒤로가기·새로고침·딥링크 |
| 코스 탭 | 저장된 코스가 있으면 저장 화면으로 | 4단계에서 같은 동작 구현(지금은 `/course`) | 저장 상태가 아직 없음 |
| 탭 접근성 | `<button>` | `<nav>` + 링크, 활성 탭 `aria-current="page"` | 접근성 |
| 뒤로 버튼 | 아이콘만 | 아이콘 + `aria-label`(`common.back`, 새 키) | 접근성 |
