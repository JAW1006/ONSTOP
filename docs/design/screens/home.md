# 홈

> 상태: 초안 · 최종 수정 2026-10-16 · 레거시: `HomeScreen`(832–972줄), `FlightNotice`(640–651줄), `FlightStatusLine`(655–666줄), `App` 재조회(568–615줄)
> 코드: [`src/features/home/`](../../../src/features/home/), [`src/features/time-safe/`](../../../src/features/time-safe/) · 데이터: [data](../data.md)

## 목적
Time-Safe 결과를 요약해 보여주고 코스 만들기·데이유즈·짐 케어·제휴 장소로 보낸다.

## 진입/이탈
| 항목 | 내용 |
|---|---|
| 라우트 | `/` (탭: 홈) — 온보딩 완료 후 |
| 이탈 | 항공편 변경 `<` → `/onboarding?step=2` · Time-Fit 카드/더보기 → `/course` · 숙소 카드 → `/booking/:roomId` · 데이유즈 더보기 → 첫 숙소 예약 · 짐 케어 배너 → `/luggage` |

## 구성 (위→아래)
| 블록 | 내용 | 문구 키 |
|---|---|---|

| **Time-Safe 카드** | `<`(항공편 변경) · 방패 아이콘 · "Time-Safe · 도착 편명" · 새로고침 · 실시간/데모 배지 / 도착편 줄(+지연 배지) / 연결편 줄 / 총 환승 시간 / 외출 가능 시간(큰 숫자) + 도착·복귀 추천 / 버퍼 구성 줄(예상) + 출국장 실시간 배지(T1/T2 또는 "실시간 아님") / 외출 불가면 경고 박스 | `flight.*`, `timeSafe.*` |
| Time-Fit | 제목·부제·더보기 / 카테고리 7개 알약(관심사 강조) / "카테고리를 골라 나만의 환승 코스를 만들어보세요 · 만들기 >" | `home.timeFit.*`, `category.*` |
| 데이유즈 | 제목·부제·더보기 / 숙소 10개 가로 스크롤(사진·추천 배지·이름·공항 N분·시간 범위·샤워/휴식/짐보관·가격~/블록) | `home.dayuse.*`, `dayuse.*`, `unit.*` |

## 상태·데이터
| 항목 | 위치 |
|---|---|
| 항공편·Time-Safe | `useTimeSafe()` (온보딩과 같은 쿼리 캐시) |
| 재조회 | 2분 자동(온보딩 완료 후) + 새로고침 버튼 → 도착·출발(·T1 대기) 쿼리 `refetch` |
| 변경 감지 | `useFlightChangeNotice()` — 같은 편명끼리 비교. **복귀 추천 시각 변경이 도착 시각 변경보다 우선**(레거시 동일) |
| 숙소·장소 | `src/data` |

## 빈/오류/로딩
| 상황 | 표시 |
|---|---|
| 재조회 중 | 새로고침 아이콘 회전, 버튼 비활성 |
| 재조회 실패 | 조용히 이전 값 유지(레거시 동일) |
| 외출 불가 | Time-Safe 카드 경고 박스, Time-Fit 카드 비활성(흐리게, "외출 불가" 문구), 더보기 숨김 |
| 연결편 없음(데모) | "데모값" 배지 — 온보딩 가드 때문에 정상 흐름에선 나오지 않음 |
