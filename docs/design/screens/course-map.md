# 코스 지도 (코스 빌더 · 저장된 코스)

> 상태: **확정 — 구현 완료(4단계)** · 최종 수정 2026-10-16
> 레거시: `Course`(1638–1971줄), `CourseMap`(1387–1635줄), `SavedCourseScreen`(1976–2070줄)
> 시안: `course_map_mock_v2.png`(방향 예시, 숫자는 설명용) · 코드: [`src/features/course/`](../../../src/features/course/)
> 공식: [time-fit](../../formulas/time-fit.md) · 토큰: [design-tokens](../design-tokens.md) "색 역할 규칙"·"선 스타일 규칙" · 비교: [results](../../results/2026-10-16-course-map-compare.md)

## 목적

데이유즈 숙소를 거점으로 장소를 골라 코스를 만들고, **시간 예산(사용/가용)과 복귀 시각을 장소를 넣고 뺄 때마다 바로** 보여준다.

## 진입/이탈

| 항목      | 내용                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------------------- |
| 라우트    | `/course`(빌더), `/course/saved`(저장된 코스)                                                                 |
| 진입      | 코스 탭(FAB)·홈 Time-Fit 카드 — **저장된 코스가 있으면 `/course/saved`**(레거시 동일)                         |
| 이탈      | 저장 → `/course/saved` · "수정하기" → `/course`(저장 내용 불러옴) · "이 숙소로 예약하기" → `/booking/:roomId` |
| 외출 불가 | 화면은 열리지만 이유 표시 + 숙소 선택·장소 추가·카테고리·자동 추천·저장·예약 비활성                           |

## 구성 (위→아래)

| #   | 블록                          | 내용                                                                                                                                                                                                                                                                                                                                                                                                   |
| --- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 헤더                          | "내 코스" + 도착 편명 · "인천 T1/T2"(도착 터미널 `P01`·`P02`→T1, `P03`→T2)                                                                                                                                                                                                                                                                                                                             |
| 2   | 지도(`CourseMap` → `MapView`) | 핀: 공항(✈, ink) · 선택한 호텔(H, 금색, 이름) · 다른 호텔(작은 회색 H, 탭하면 선택) · 고른 장소(번호, 파랑, 이름). 구간 선 + **칩**(수단 아이콘 + 시간 크게 + 거리 작게). 장소가 있으면 마지막 장소→호텔 = "숙소로" 칩(일반 이동선, B1), 호텔→공항 = **복귀**(빨간 긴 파선, "복귀" 칩). 후보 장소·참고용 업종(병원·약국)은 회색 점(확대 레벨 6 이하)                                                   |
| 3   | 선 범례                       | "선 모양 = 이동수단 … · 약 = 어림한 값"                                                                                                                                                                                                                                                                                                                                                                |
| 4   | 선택 구간 정보                | 칩·선을 누르면 그 구간만 굵고 진하게, 나머지는 옅게 + 한 줄: 수단 · 시간 · 거리 · 환승 N회 · 요금(있는 값만)                                                                                                                                                                                                                                                                                           |
| 5   | **요약 패널**(지도 아래 고정) | "사용 X / 가용 Y" + 여유(초록)/초과(빨강) 배지 · 시간 예산 막대(준비·이동·체류, 가용을 넘는 부분은 초과=빨강, 남으면 여유) · 막대 아래 구간 이름·분 수 · 복귀 도착 목표 · 마지막 장소(또는 숙소)에서 출발 HH:MM까지 · 장소가 있으면 숙소에서 출발 HH:MM까지(B1) · 블록 초과 시 "숙소 복귀 예상 HH:MM — 이용 종료 HH:MM보다 N분 늦어요" · 초과 시 ⚠ 경고 + "복귀 도착 예상 HH:MM (목표 HH:MM보다 늦음)" |
| 6   | 숙소 선택                     | 가로 카드 10개(필수)                                                                                                                                                                                                                                                                                                                                                                                   |
| 7   | 활동 카테고리                 | 칩 6개(휴식 제외), 기본 = 관심사 중 활동 카테고리                                                                                                                                                                                                                                                                                                                                                      |
| 8   | 자동 추천                     | 버튼 + "시간에 맞춰 자동 추천 · 카테고리마다 남은 시간에 들어가는 장소를 1곳씩 담아요"(A7) + 이동시간 조회 상태. 0곳이면 "남은 시간 안에 들어가는 장소가 없어요…" 안내                                                                                                                                                                                                                                 |
| 9   | 장소 목록                     | 숙소에서 가까운 순 6개 + 더보기. 카드: **회색 카테고리 배지(아이콘+글자)** · 제휴 AD · 이름 · 지역 · 수단 아이콘 · 이동(약) · 체류 · 환승 내 가능/시간 빠듯 · 가격 · 추가/제거 → 이름 탭 시 상세 시트                                                                                                                                                                                                  |
| 10  | 내 일정                       | 공항 밖(짐 맡기기) → 체크인 → 장소들 → **숙소 복귀·짐 찾기**(장소가 있을 때, B1) → 공항 복귀("복귀 도착 목표 HH:MM" — 레거시 "알림 · 여유 30분" 대체). 늦으면 복귀 시각 빨강. 장소 삭제                                                                                                                                                                                                                |
| 11  | 저장                          | "코스 저장하기"(초과여도 저장 가능, 흐리게 — 레거시 동일)                                                                                                                                                                                                                                                                                                                                              |

저장된 코스 화면: 숙소 카드 · 지도(다른 호텔·후보 점 없음) · 범례 · 요약 패널 · 일정(삭제 없음) · 수정하기 / 이 숙소로 예약하기.

## 이동 시간·거리 데이터 — 실제 경로 값 vs 근사값

| 구간                              | 판정(직선)       | 시간                                                                               | 거리(칩)                                      | 표기                     |
| --------------------------------- | ---------------- | ---------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------ |
| 도보                              | ≤ 1.2km          | **근사**(직선 ÷ 4.5km/h, 조회 안 함)                                               | 표시 안 함                                    | "약 N분"                 |
| 택시(자동차)                      | 1.2~6km          | **실제 경로**(카카오모빌리티)                                                      | 실제(`distanceM`)                             | "N분 · N.Nkm"            |
| 대중교통                          | ≥ 6km            | **실제 경로**(ODsay)                                                               | 실제(ODsay `totalDistance`, 도보 포함 총거리) | "N분 · N.Nkm"            |
| 대중교통 실패 → 자동차            | ≥ 6km            | 실제 경로(카카오)                                                                  | 실제                                          | 택시로 표시              |
| **코스 빌더(확정 전) 전 구간**    | —                | **보수적 근사만** — 실제 경로 조회 안 함(직선 × 6분/km, 도보 직선 × 1.3 ÷ 4.5km/h) | 표시 안 함                                    | "약 N분"                 |
| 저장된 코스에서 조회 중·조회 실패 | —                | 같은 보수적 근사                                                                   | 표시 안 함                                    | "약 N분"                 |
| 복귀(마지막 → 공항)               | 위와 같음        | 위와 같음                                                                          | 위와 같음                                     | "복귀 N분"/"복귀 약 N분" |
| 후보 목록의 "이동 N분"            | 숙소→후보        | **근사만**(후보 구간 미리 조회 안 함)                                              | —                                             | "약 N분"                 |
| 자동 추천·"환승 내 가능" 판정     | 고른 일정 + 후보 | **근사만**                                                                         | —                                             | (판정만)                 |

환승 수 = `busTransitCount + subwayTransitCount − 1`(ODsay 실제 응답에서 두 값이 "탄 횟수"와 같게 나옴 — 해석 **미검증**).
