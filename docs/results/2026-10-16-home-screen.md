# 홈 화면 이식 — 레거시 비교

> 상태: 확정 · 2026-10-16 · 명세: [screens/home](../design/screens/home.md) · 데이터: [data](../design/data.md)

## 목표
레거시 `HomeScreen`·`FlightNotice`·재조회를 옮기고, 같은 입력에서 결정된 변경 외에는 레거시와 같게 보이는지 확인한다.

## 방법
1. **데이터 추출** — `scripts/extract-legacy-data.mjs`로 `ROOMS`·`PLACES`·`AD_PLACES`·`HOT_PLACE_IDS`를 그대로 JSON화. 숙소 가격·시간대·이동시간을 레거시 원문과 대조하는 테스트 포함([`data.test.ts`](../../src/data/data.test.ts)).
2. **자동 테스트** — [`HomeScreen.test.tsx`](../../src/features/home/HomeScreen.test.tsx) 12건(모의 API).
3. **나란히 비교** — 임시 모의 API(실제 키 미사용)로 레거시와 새 앱 모두 온보딩(한국어, KE085 → MU2043) → "스마트 코스 추천" → 홈까지 같은 순서로 조작해 Time-Safe 카드 텍스트·스크린샷 비교.

## 결론
- Time-Safe 카드는 결정 사항(A1·A7) 외에 레거시와 글자까지 같다.
- 항공편 변경 배너는 레거시 규칙(복귀 시각 변경 우선)을 따르고, 편명을 바꿔 다시 조회한 경우는 띄우지 않는다(레거시엔 해당 경로 없음).
- 빌드 경고: 메인 JS 563KB(> 500KB 경고 기준), 로고 PNG 405KB → [STATUS](../STATUS.md) "개선 후보".
