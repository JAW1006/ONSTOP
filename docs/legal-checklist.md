### 0-2. "외출 가능 ≠ 입국 가능"
앱은 항공편 시각으로 **공항 밖에서 쓸 수 있는 시간**을 계산할 뿐, 그 사람이 **입국할 수 있는지**(국적·비자·환승 조건·여행 허가)는 판단하지 않는다. 외출 가능 시간이 나오면 입국도 가능하다고 오해할 수 있다.

| # | 확인 필요 항목 | 왜 | 확인 방법 | 결과 |
|---|---|---|---|---|
| 0-2-a | 국적별 무비자 입국·전자여행허가(K-ETA)·환승객 무비자 제도 등 **입국 조건의 종류와 최신 기준** | 앱 사용자 대부분이 외국인 환승객 | 공식 안내 확인: 하이코리아(hikorea.go.kr), 전자여행허가 K-ETA(k-eta.go.kr), 법무부 출입국·외국인정책본부, 인천공항 환승 안내(airport.kr) — 앱에 조건을 **직접 판정하지 않는 것**을 기본으로 | |
| 0-2-b | 환승객이 입국했다가 다시 출국할 때 추가로 필요한 절차·시간(수하물 재위탁, 재보안검색 등) | 버퍼(입국심사·보안검색)에 반영됐는지 | 항공사·공항 안내 확인, 버퍼 값 근거와 함께([time-safe](formulas/time-safe.md)) | |
| 0-2-c | 입국 가능 여부를 앱이 안내하지 않을 때의 **고지 위치·문구** | 오해 방지 | 아래 안 중 선택 후 전문가 검토 | |
| 0-2-d | 입국 불가로 외출하지 못한 경우 예약(데이유즈)의 취소·환불 처리 | 예약 요청 후 입국 거절 가능성 | 호텔 인터뷰 4장, 환불 규정(3-2) | |

**온보딩 안내·면책 문구 방안 (초안 — 확정 아님, 전문가·원어민 검토 필요)**
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | 항공편 조회 결과 카드 아래 고정 안내: "외출 가능 시간은 항공편 시각으로 계산한 참고값이에요. 입국 가능 여부(국적·비자·환승 조건)는 TimeStay가 확인하지 않아요. 공항 밖으로 나가기 전에 공식 안내에서 확인해 주세요." + 공식 사이트 링크 | 단순, 모든 사용자에게 노출 | 읽지 않고 넘길 수 있음 |
| B | A + "스마트 코스 추천" 전에 **확인 체크**("입국 조건을 확인했어요") | 고지 사실이 남음 | 단계 하나 추가 |
| C | 온보딩에 국적 선택 → 국적별 조건을 앱이 안내 | 친절 | 조건 데이터를 앱이 관리·보증해야 함 — 오류 시 책임 범위 큼(권장하지 않음, 검토만) |

이용약관 면책(초안 방향): 계산은 참고용, 입국·탑승 책임은 이용자, 외부 데이터(항공편·이동시간) 한계 — 6-1·6-3·6-5와 함께 작성.
