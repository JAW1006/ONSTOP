# 서비스 개요

> 상태: 초안 · 최종 수정 2026-10-16

**TimeStay** — 인천공항 환승 외국인 관광객을 위한 데이유즈 + AI 큐레이션 플랫폼.
태그라인: "짐은 맡기고, 환승 시간을 인천에서" (Transit · Drop · Fly Light)

## 핵심 기능
| 기능 | 한 줄 정의 | 공식 |
|---|---|---|
| Time-Safe | 도착편·연결편 입력 → 공항 밖에서 실제로 쓸 수 있는 시간 계산 | [time-safe.md](../formulas/time-safe.md) |
| Time-Fit | 남은 시간 안에 들어가는 코스 추천 | [time-fit.md](../formulas/time-fit.md) |
| 데이유즈 예약 | 3~9시간 타임블록, 숙소 = 코스 거점 | [dayuse-pricing.md](../formulas/dayuse-pricing.md) |
| 짐 케어 | 공항 보관 / 호텔 배송 / 상권 배송 | — |

예시(사용자 제시, 2단계에서 확정): 총 4h21m − 50분 − 게이트 30분 = **3h01m**

## 사용자 흐름
온보딩(언어 → 관심 활동 → 항공편 조회) → 홈(Time-Safe 카드) → 코스 만들기(숙소 선택 → 카테고리 → 지도 핀) → 데이유즈 예약 → 확인(QR)

하단 탭: 홈 / 짐 케어 / **코스(가운데 FAB)** / 예약 / 마이

## 지원 언어
영어(기본) · 중국어 간체 · 일본어 · 베트남어 · 한국어 (항공편 API는 베트남어 미지원 → 영어로 조회)

## 수익 모델
| 항목 | 수수료 | 출처 | 검증 |
|---|---|---|---|
| 데이유즈 예약 | 12% | 사업 계획(사용자 제공, 2026) | 미검증 |
| 액티비티 예약 | 15% | 사업 계획(사용자 제공, 2026) | 미검증 |
| 제휴 노출(CPC) | 200~500원/클릭 | 사업 계획(사용자 제공, 2026) | 미검증 |

상수 이름은 [dayuse-pricing.md](../formulas/dayuse-pricing.md) 참조. 레거시 코드에는 수수료 계산이 없다.
