# 제휴 호텔 인터뷰 질문지 (5곳)

> 상태: 초안 · 2026-10-16 · 답변은 [design/data-verification](../design/data-verification.md) "호텔별 시간 블록·가격 입력"과 이 문서 끝 "답변 기록"에 적는다.
> 목적: 결제·정산 구조([ADR-0004](../decisions/ADR-0004-payment.md)), 데이유즈 시간 블록·가격(A9), 예약 요청 방식([screens/booking](../design/screens/booking.md)), 법률 확인 항목([legal-checklist](../legal-checklist.md))에 필요한 사실 확인.
> 원칙: 숫자는 호텔이 **실제로 판매하는 상품 그대로** 받는다(계산식으로 추정하지 않음). 답을 못 받은 항목은 "미확인".

## 1. 데이유즈 상품 (시간 블록·가격)
| # | 질문 | 왜 |
|---|---|---|
| 1-1 | 시간 단위(대실·데이유즈) 객실을 판매하나요? 숙박업 신고 업종에서 시간 단위 판매가 가능한가요? | 데이유즈 판매 적법성(legal 1-4) |
| 1-2 | 판매하는 **시간 블록**을 모두 알려주세요(예: 3시간·4시간·6시간…). 블록별 **판매가**는? | A9 — 블록·가격표를 그대로 사용 |
| 1-3 | 요일·시간대·성수기별로 가격이 다른가요? 다르면 표로 받을 수 있나요? | 가격 데이터 구조 |
| 1-4 | 체크인 가능한 시각 범위(예: 09:00~20:00)와, 블록을 시작할 수 있는 마지막 시각은? | 체크인 슬롯 |
| 1-5 | 객실 타입별 차이가 있나요(기본 1종으로 시작해도 되는지)? | 데이터 단순화 |
| 1-6 | 포함 서비스(샤워·휴식·짐 보관·어메니티)와 추가 요금 항목은? | 화면 "포함" 문구 |
| 1-7 | 연장(블록 추가) 가능 여부와 요금은? | 복귀 시각 변경 대응 |
| 1-8 | 하루에 데이유즈로 팔 수 있는 객실 수(재고)는 어떻게 알 수 있나요? | 예약 요청 → 확인 방식 |

## 2. 예약·확인 방식
| # | 질문 | 왜 |
|---|---|---|
| 2-1 | 예약 요청을 어떻게 받기를 원하나요(이메일·전화·메신저·기존 예약 시스템)? | "예약 요청 → 호텔 확인" 흐름 |
| 2-2 | 요청을 받고 **확인(수락/거절)까지 걸리는 시간**은? 야간(22시 이후)·새벽에도 확인 가능한가요? | 환승객은 시간이 촉박 — 응답 시간 표시 |
| 2-3 | 외국인 투숙객 체크인에 필요한 서류(여권 확인 등)는? 플랫폼이 미리 받아야 하는 정보가 있나요? | 개인정보 최소 수집(ADR-0003, legal 2-2) |
| 2-4 | 영어(또는 중국어·일본어·베트남어) 응대가 가능한가요? | 현장 경험 |
| 2-5 | 짐만 맡기는 고객(객실 미이용)을 받나요? 요금은? | 짐 케어 |

## 3. 결제·정산
| # | 질문 | 왜 |
|---|---|---|
| 3-1 | **예약금(또는 전액)을 누가 받기를 원하나요** — 호텔 직접 / 플랫폼이 받아 정산? | ADR-0004 A/B |
| 3-2 | 호텔이 직접 받는다면: 받을 수 있는 결제 수단(해외 카드·Alipay·WeChat Pay·현금·결제 링크)은? | 외국인 결제 가능 여부 |
| 3-3 | 플랫폼이 받는다면: 원하는 **정산 주기**(건별·주·월)와 정산 증빙 방식은? | 정산 설계 |
| 3-4 | 수수료(사업 계획 12%, 미검증) 수준에 대한 의견, 다른 플랫폼에서 받는 수수료 범위 | 수익 모델 검증 |
| 3-5 | 플랫폼이 월 정산으로 수수료를 청구한다면, 매출(이용 건수) 확인을 어떻게 공유할 수 있나요? | B 방식의 누락 방지 |
| 3-6 | 세금계산서·현금영수증 발행 주체 희망 | 세무(legal 3-4) |

## 4. 노쇼·취소·지연
| # | 질문 | 왜 |
|---|---|---|
| 4-1 | **노쇼** 시 처리(예약금 몰수·수수료·없음)는? | 노쇼 규정 |
| 4-2 | **취소** 규정(몇 시간 전까지 무료, 이후 수수료)은? | 환불 규정(legal 3-2) |
| 4-3 | **항공편 지연·결항**으로 못 오거나 늦게 오는 경우 예외를 두나요? 늦게 도착하면 블록 시작을 늦출 수 있나요? | 환승객 특성 |
| 4-4 | 예정보다 일찍 나가는 경우 환불이 있나요? | 복귀 시각 앞당김 |

## 5. 콘텐츠·표시
| # | 질문 | 왜 |
|---|---|---|
| 5-1 | 앱에 쓸 **사진을 제공**해 주실 수 있나요? 사용 범위(앱·광고·SNS)와 기간에 대한 **서면 허락**이 가능한가요? | 사진 사용 허락(legal 0-1) |
| 5-2 | 공식 외국어 상호(영·중·일·베) 표기가 있나요? | 다국어 이름 |
| 5-3 | 정확한 주소(도로명)와, 앱에 표시할 위치(좌표)를 직접 제공해 주실 수 있나요? | 좌표 출처 교체([external-apis](../operations/external-apis.md) "좌표 교체 계획") |

| 5-5 | "추천"·"제휴" 표시에 대한 의견 | 광고 표시(legal 4-1) |
