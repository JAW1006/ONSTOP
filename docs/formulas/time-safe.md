# Time-Safe — 외출 가능 시간

> 상태: 초안 · 최종 수정 2026-10-16
> 코드: [`src/domain/time-safe.ts`](../../src/domain/time-safe.ts) · 테스트: [`time-safe.test.ts`](../../src/domain/time-safe.test.ts) · 상수: [`constants.ts`](../../src/domain/constants.ts)

## 정의

### 기존 동작 (레거시 `app/index.html` 361–365, 564–566줄)
```
securityMin = (연결편 터미널 == LIVE_SECURITY_TERMINAL && 실시간 평균 있음) ? 실시간 평균 : SECURITY_BUFFER_MIN
bufferMin   = securityMin + GATE_CUTOFF_MIN

연결편 없음 → returnBy = arrive + LAYOVER_BUDGET, canGoOut = true
연결편 있음 → canGoOut = (depart − bufferMin − arrive) ≥ MIN_STAY
              returnBy  = canGoOut ? depart − bufferMin : arrive
stayMin = returnBy − arrive          (홈·온보딩 표시값)
```
- 도착 시각 = 실시간 예상 우선, 없으면 예정.
- 출발 시각 = 실시간 예상 우선, 단 예정보다 이르면 예정(조기 출발은 믿지 않음).
- 시각은 `HHMM`만 파싱(0–1439분). 날짜·자정 넘김 처리 없음.

### 결정된 공식 (2026-10-16 결정, 이슈별 커밋으로 적용)
| 이슈 | 결정 | 적용 |
|---|---|---|
| A2 자정 넘김 | 항공편에 날짜가 있으면 날짜로 계산. 없을 때만 출발 < 도착이면 다음 날. 24시간 초과는 경고. | 대기 |
| A3 T1 실시간 대기 | 대체하지 않고 `max(SECURITY_BUFFER_MIN, 실시간)` 하한 방식 | 대기 |
| A1 버퍼 구성 | 입국심사(도착 후, 짐 찾기 포함) / 보안검색·출국심사 / 게이트 여유 3개로 분리. 합계는 사용자가 근거 확인 후 결정. | 대기 |
| A5 용어 | "외출 가능 시간"(Time-Safe 결과) / "코스 가용 시간"(= 외출 가능 시간 − 준비) 분리. 준비 20분은 Time-Safe에 넣지 않음. | 대기 |

## 예시 (테스트와 동일)
| # | 입력 | 기존 동작 결과 |
|---|---|---|
| 1 | 도착 10:30, 출발 14:51 (4h21m) | 버퍼 80, 복귀 13:31, **3h01m** |
| 2 | 도착 10:00, 출발 12:20 | 남는 시간 정확히 60 → 외출 가능, 1h00m |
| 3 | 도착 10:00, 출발 12:19 | 59 → 외출 불가, 복귀 = 도착, 0 |
| 4 | 도착 10:30, 연결편 없음 | 복귀 16:30, 6h00m |
| 5 | #1 + 연결편 T1, 실시간 12분 | 버퍼 42, 복귀 14:09, 3h39m |
| 6 | 도착 22:00, 출발 01:30 | 총 −1230분 → **외출 불가** (A2 버그) |
| 7 | 출발 예정 14:50, 예상 14:40 / 15:10 | 14:50 / 15:10 |
| 8 | 출발 예정 23:50, 예상 00:10 | 23:50 (A2 버그: 지연을 조기 출발로 오인) |

## 엣지 케이스
| 상황 | 기존 동작 |
|---|---|
| 자정 넘김 | 처리 안 됨(#6, #8) → A2 |
| T1 실시간 평균이 50분보다 작음 | 그대로 대체되어 버퍼 감소(#5) → A3 |
| T2(`P03`) 연결편 | 실시간 없음, 50분 |
| 출국장 대기 API의 한계 | 조회 시점의 **T1 전체 게이트 평균**이다. 승객이 실제로 쓸 게이트, 복귀 시점의 대기시간이 아니다. |
| 시각 파싱 실패 | 도착: 데모값(10:30), 출발: 연결편 없음으로 처리(화면에서 오류 표시) |
